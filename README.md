


During my CodSoft C++ Programming Internship, I successfully completed three projects that enhanced my understanding of logic building, user interaction, and file handling in C++.
Below is a summary of the completed tasks:

 Task 1: Number Guessing Game

* Created a fun console-based game where the computer generates a random number.
* The user guesses the number and receives feedback if their guess is too high or too low.
* The game continues until the correct number is guessed.
* Improved use of loops, conditionals, and random number generation.

   Task 2: Simple Calculator

* Built a basic calculator that performs addition, subtraction, multiplication, and division.
* Allowed users to input two numbers and choose the desired operation.
* Displayed clear and accurate results with simple control flow using if–else statements.
* Strengthened understanding of operators and conditional statements in C++.

Task 3: To-Do List Manager

* Developed a console-based to-do list application to manage daily tasks.
* Features include adding, viewing, completing, and deleting tasks.
* Used simple data structures and if–else logic to manage the task list.
* Helped practice modular programming and logical structuring of code.
